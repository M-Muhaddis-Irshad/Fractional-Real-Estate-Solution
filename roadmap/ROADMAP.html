Phase breakdown

what ships, when, and why it matters to investors

Phase 1 · Foundation

Done
Auth · Listings · UI overhaul · Story
  • JWT role-based auth — investor & super-admin, with account approval / suspension workflow
  • Property listings with admin review (approve / reject / feature / investing toggle)
  • Complete UI overhaul — migrated to Next.js 16 (App Router) + TypeScript
  • Public site: landing, Our Story, sign-up / login / password reset
Benefit to investor

Sign up, browse vetted listings and trust a polished, professional platform.

Phase 2 · Core Investment Flow

Done
Requests · Approval · Fees · Tokens
  • Share purchase requests — pending → approved / rejected, with optional manual admin gate
  • Atomic share allocation with oversell guard — shares can never be double-sold
  • Transparent team fee — 2.25% default, computed up-front on every request
  • Flux Chain ownership tokens — hash-linked ledger, verifiable via verifyChain
  • Separate investor Portfolio / Ledger and internal Team Console
Benefit to investor

Instant, transparent settlement with a verifiable ownership record.

Phase 3 · Payments & Onboarding

In Progress
Crypto · Carousel · OAuth
  • Coinbase Commerce checkout — BTC / ETH / USDC / USDT, live-ready with signed HMAC webhooks
  • Demo mode auto-confirms ~20s so the full flow is testable end-to-end today
  • 5-slide onboarding carousel on first login, persisted per account
  • Google / Apple OAuth — planned, awaiting Apple Developer account
Benefit to investor

Crypto-native checkout + a guided first-run experience lowers the barrier to a first investment.

Phase 4 · Production Readiness

Pending
Compliance · Live keys · Hardening
  • Legal / compliance review — KYC/AML, entity formation, terms & conditions
  • Live Coinbase Commerce API keys + webhook secret (currently demo mode)
  • Fiat payment gateway integration (card / bank — currently simulated)
  • Real share-supply validation, ledger audits & security hardening
  • Apple Developer account + Google/Apple OAuth sign-in
Benefit to investor

Turns a strong demo into a platform ready to handle real money at scale.
